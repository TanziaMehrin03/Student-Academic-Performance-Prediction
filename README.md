Student Academic Performance Prediction Using Machine Learning
About the Project
This is a collaborative machine learning project developed to predict students' final mathematics grades based on academic, personal, and social factors.

We used the Student Performance dataset and implemented multiple regression algorithms to compare their predictive performance.

Objectives
Analyze student academic performance.

Perform exploratory data analysis (EDA).

Preprocess numerical and categorical data.

Develop and compare machine learning regression models.

Evaluate model performance using MSE and R².

Dataset
Source: UCI Machine Learning Repository

Dataset: Student Performance (Mathematics)

Records: 395

Target variable: G3 (Final Mathematics Grade)

Algorithms Used
Random Forest Regression

Linear Regression

Gradient Boosting Regression

Support Vector Regression (SVR)

Neural Network (MLP Regressor)

Best Model Performance
Random Forest Regression achieved:

Mean Squared Error (MSE): 3.83

R² Score: 0.81
